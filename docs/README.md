# Documentation guide

## Project use

- [Project README](../README.md) explains what the runtime is, what works, and how to run it.
- [Engine provenance](../engine/UPSTREAM.md) records the imported C1 source snapshots.
- [Historical engine notes](../engine/README.md) describe the earlier native desktop lineage and
  are not authoritative for this browser workspace.
- [Verification record](VERIFICATION.md) records dated build and owned-data checks. Generated
  artifacts and game data are not committed.

## Publication and rights

- [License notice](../LICENSE.md) states that there is no project-wide open-source license.
- [Rights and licenses](../RIGHTS_AND_LICENSES.md) explains the restricted source-available
  boundary and unresolved upstream rights.
- [Copyright and provenance notice](../NOTICE.md) identifies source references and trademarks.
- [Third-party notices](../THIRD_PARTY_NOTICES.md) covers vendored dependencies.
- [Privacy](../PRIVACY.md) explains local file access and browser storage.
- [Security](../SECURITY.md) explains how to report sensitive problems.
- [Contributing](../CONTRIBUTING.md) explains which reports are welcome and why code contributions
  are closed.
- [Public release checklist](PUBLIC_RELEASE_CHECKLIST.md) is for maintainers preparing repository
  visibility.
- [Source-publication decision](PUBLICATION_DECISION.md) records the owner's chosen boundary.
- [Legal-review brief](LEGAL_REVIEW_BRIEF.md) is a factual handoff, not a legal opinion.
